# Recursos para modelado 3D

Generados con la herramienta integrada ImageGen. Referencias conceptuales para los tres planetas del catálogo actual; no son modelos 3D ni representan una composición geológica científica. Metal y circuito son materiales recuperados, y el cristal energético es ficticio.

## Cantidades actuales por planeta

| Planeta | Metal | Circuito | Recurso exclusivo |
|---|---:|---:|---|
| Neptuno | 6 | 3 | 3 cristales de hielo |
| Marte | 3 | 3 | 4 minerales rojos |
| Saturno | 5 | 2 | 5 cristales energéticos |

Las cantidades suman las tres recetas de cada planeta en Assets/02_Prefabs/Tablet/j_PlanetRecipeCatalog.asset. El catálogo no fue modificado.
